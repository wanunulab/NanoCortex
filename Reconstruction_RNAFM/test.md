# RNA-FM Model User Guide

## How to Distinguish If Training Is Needed?

### 🔵 **Functions That Do Not Require Training** (Directly Use Pretrained Model)

These functions use the already pretrained RNA-FM model and can be used directly without training:

#### 1. **Sequence Embedding Generation** (`embed_sequences`)
- **Purpose**: Convert RNA sequences into numerical vectors (embeddings)
- **Model**: Uses pretrained RNA-FM or mRNA-FM model
- **Is Training Required**: ❌ **No**
- **Use Cases**:
  - Sequence similarity analysis
  - Clustering analysis
  - Input features for downstream tasks

#### 2. **Secondary Structure Prediction** (`predict_secondary_structure`)
- **Purpose**: Predict the secondary structure of RNA sequences
- **Model**: Uses pretrained secondary structure prediction model (`model_type="ss"`)
- **Is Training Required**: ❌ **No**
- **Use Cases**:
  - Direct prediction of RNA secondary structure
  - Analyze RNA folding patterns
- **Output**:
  - Smart output: Use the `--output` parameter to auto-detect format
    - Directory path: Generates all formats automatically (PNG images and CT structure files), names files with sequence IDs
    - File path: Auto-detects format based on extension (.npy, .png, .ct, etc.)

#### 3. **t-SNE Visualization**
- **Purpose**: Reduce high-dimensional embeddings to 2D for visualization
- **Is Training Required**: ❌ **No** (This is a data analysis method, not a model)

---

### 🟡 **Functions That Require Training** (Train Classifier Based on Pretrained Embeddings)

These functions require training a simple classifier on embeddings generated by the pretrained model:

#### 1. **RNA Family Classification** (`RNATypeClassifier`)
- **Purpose**: Classify RNA sequences into different RNA families
- **Training Workflow**:
  1. Use pretrained model to generate embeddings (no training needed)
  2. Train a linear classifier based on the embeddings (training required)
- **Is Training Required**: ✅ **Classifier needs training**
- **Training Steps**:
  ```python
  # 1. Generate embeddings (no training needed)
  embedder = RNAFMEmbedder(model_type="rna")
  embeddings = embedder.embed_sequences(sequences, mean_pool=True)
  
  # 2. Prepare data
  x_train, y_train, x_val, y_val, x_test, y_test = stratified_split(...)
  
  # 3. Create classifier model
  model = RNATypeClassifier(in_dim, num_class)
  
  # 4. Train classifier (training required)
  train_classifier(model, train_loader, val_loader, test_loader, ...)
  ```

#### 2. **mRNA Expression Level Prediction**
- **Purpose**: Predict the expression level of mRNA (high/low)
- **Training Workflow**:
  1. Use pretrained model to generate embeddings (no training needed)
  2. Train a binary classifier on the embeddings (training required)
- **Is Training Required**: ✅ **Classifier needs training**
- **Training Steps**: Same as RNA family classification

---

## Quick Decision Methods

### Criteria:

1. **If only calling `RNAFMEmbedder` methods**:
   - `embed_sequences()` → ❌ No training required
   - `predict_secondary_structure()` → ❌ No training required

2. **If you need to create and train an `RNATypeClassifier`**:
   - ✅ Classifier training required

3. **If it’s only data analysis or visualization**:
   - t-SNE, plotting, etc. → ❌ No training required

## Usage Examples

### Example 1: Direct Use (No Training Needed)

```python
from function import RNAFMEmbedder

# Initialize model (automatically loads pretrained weights)
embedder = RNAFMEmbedder(model_type="ss")

# Generate embeddings (no training needed)
sequences = [("RNA1", "GGGUGCGAUCAUACCAGCACUAAUGCCCUCCUGGGAAGUCCUCGUGUUGCACCCCU")]
embeddings = embedder.embed_sequences(sequences)

# Predict secondary structure (no training needed)
ss_prob = embedder.predict_secondary_structure(sequences)
```

### Example 2: Training Classifier Needed

```python
from function import RNAFMEmbedder, RNATypeClassifier, train_classifier, stratified_split

# 1. Generate embeddings (no training needed)
embedder = RNAFMEmbedder(model_type="rna")
embeddings = embedder.embed_sequences(sequences, mean_pool=True)

# 2. Prepare data
x_train, y_train, x_val, y_val, x_test, y_test = stratified_split(embeddings, labels)

# 3. Create classifier
model = RNATypeClassifier(in_dim=embeddings.shape[1], num_class=num_classes)

# 4. Train classifier (training required)
train_classifier(model, train_loader, val_loader, test_loader, ...)
```

## Image Output Functionality

All visualization features support saving images to files:

| Feature               | Output Parameter   | Saved File(s)                          |
|-----------------------|-------------------|----------------------------------------|
| Secondary Structure Prediction | `--output` (dir)    | Generates all formats (.png & .ct), named by sequence ID |
| Secondary Structure Prediction | `--output` (file)   | Detects format by extension (.npy, .png, .ct) |
| Clustering Visualization       | `--output`          | t-SNE plot (.png etc.)                |
| Classification Training        | `--output`          | loss_history.png, accuracy_history.png|
| Expression Prediction Training | `--output`          | loss_history.png, accuracy_history.png|

**Usage Examples**:
```bash
# Save secondary structure visualization
# Smart output: specify directory, generates all formats (uses sequence ID as filename)
ReRNAFM predict_ss --sequences_file seq.fasta --output ./results/
# Will generate: maqe.png and maqe.ct (if the sequence ID is maqe)

# Save clustering result
ReRNAFM cluster --fasta_folder /path/to/fasta --output cluster.png

# Save training history
ReRNAFM classify --fasta_folder /path/to/fasta --output ./results/
```

## Summary

| Feature            | Training Required | Description           |
|--------------------|------------------|-----------------------|
| Sequence Embedding | ❌ No             | Uses pretrained model |
| Secondary Structure| ❌ No             | Uses pretrained model |
| t-SNE Visualization| ❌ No             | Data analysis method  |
| RNA Family Clsf.   | ✅ Yes            | Train a classifier    |
| mRNA Expr. Pred.   | ✅ Yes            | Train a classifier    |

**Key Points**:
- The RNA-FM base model is pretrained, no training required
- Classification tasks require training a simple classifier on embeddings
- Classifier training usually takes just a few to tens of minutes depending on the data size
- **All images can be saved to file**, suitable for server environments without GUI
