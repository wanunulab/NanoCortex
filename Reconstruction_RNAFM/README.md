# RNA-FM Model Usage Guide

## How to Tell Whether Training is Needed?

### 🔵 **Functions That Do NOT Require Training** (Use Pretrained Model Directly)

These features use a pretrained RNA-FM model and are ready to use directly without any training:

#### 1. **Sequence Embedding Generation** (`embed_sequences`)
- **Purpose**: Convert RNA sequences to numerical vectors (embeddings)
- **Model**: Uses pretrained RNA-FM or mRNA-FM model
- **Training Required?**: ❌ **Not required**
- **Use Cases**:
  - Sequence similarity analysis
  - Clustering analysis
  - As input features for downstream tasks

#### 2. **Secondary Structure Prediction** (`predict_secondary_structure`)
- **Purpose**: Predict the secondary structure of RNA sequences
- **Model**: Uses pretrained secondary structure prediction model (`model_type="ss"`)
- **Training Required?**: ❌ **Not required**
- **Use Cases**:
  - Straightforward RNA secondary structure prediction
  - Analyzing RNA folding patterns
- **Output**:
  - Smart output: Use the `--output` parameter, auto-detects format
    - Directory path: Generates all formats automatically (.png images and .ct structure files) named with sequence IDs
    - File path: Automatically detects format by extension (.npy, .png, .ct, etc.)

#### 3. **t-SNE Visualization**
- **Purpose**: Reduces dimensionality of embeddings to 2D for visualization
- **Training Required?**: ❌ **Not required** (This is a data analysis method, not a model)

---

### 🟡 **Functions That REQUIRE Training** (Train a Classifier Based on Pretrained Embeddings)

These features require you to train a simple classifier on embeddings generated by the pretrained model:

#### 1. **RNA Family Classification** (`RNATypeClassifier`)
- **Purpose**: Classify RNA sequences into different RNA families
- **Training Process**:
  1. Generate embeddings with pretrained model (**No training needed**)
  2. Train a linear classifier on the embeddings (**Training required**)
- **Training Required?**: ✅ **Classifier needs to be trained**
- **Training Steps**:
  ```python
  # 1. Generate embeddings (no training needed)
  embedder = RNAFMEmbedder(model_type="rna")
  embeddings = embedder.embed_sequences(sequences, mean_pool=True)
  
  # 2. Prepare data
  x_train, y_train, x_val, y_val, x_test, y_test = stratified_split(...)
  
  # 3. Create classifier model
  model = RNATypeClassifier(in_dim, num_class)
  
  # 4. Train classifier (training required)
  train_classifier(model, train_loader, val_loader, test_loader, ...)
  ```

#### 2. **mRNA Expression Level Prediction**
- **Purpose**: Predict high/low mRNA expression levels
- **Training Process**:
  1. Generate embeddings with pretrained model (**No training needed**)
  2. Train a binary classifier on the embeddings (**Training required**)
- **Training Required?**: ✅ **Classifier needs to be trained**
- **Training Steps**: Similar to RNA family classification

---

## Quick Judgment Guide

### Criteria:

1. **If you simply call a method of `RNAFMEmbedder`:**
   - `embed_sequences()` → ❌ No training required
   - `predict_secondary_structure()` → ❌ No training required

2. **If you need to create and train a `RNATypeClassifier`:**
   - ✅ Classifier must be trained

3. **If it is for data analysis or visualization only:**
   - t-SNE, plotting, etc. → ❌ No training required

## Usage Examples

### Example 1: Direct Usage (No Training Required)

```python
from function import RNAFMEmbedder

# Initialize model (automatically loads pretrained weights)
embedder = RNAFMEmbedder(model_type="ss")

# Generate embeddings (no training needed)
sequences = [("RNA1", "GGGUGCGAUCAUACCAGCACUAAUGCCCUCCUGGGAAGUCCUCGUGUUGCACCCCU")]
embeddings = embedder.embed_sequences(sequences)

# Predict secondary structure (no training needed)
ss_prob = embedder.predict_secondary_structure(sequences)
```

### Example 2: Training a Classifier Required

```python
from function import RNAFMEmbedder, RNATypeClassifier, train_classifier, stratified_split

# 1. Generate embeddings (no training needed)
embedder = RNAFMEmbedder(model_type="rna")
embeddings = embedder.embed_sequences(sequences, mean_pool=True)

# 2. Prepare data
x_train, y_train, x_val, y_val, x_test, y_test = stratified_split(embeddings, labels)

# 3. Create classifier
model = RNATypeClassifier(in_dim=embeddings.shape[1], num_class=num_classes)

# 4. Train classifier (training required)
train_classifier(model, train_loader, val_loader, test_loader, ...)
```

## Image Output Functionality

All visualization features support saving images to file:

| Function             | Output Param        | Saved Files                                         |
|----------------------|--------------------|-----------------------------------------------------|
| Secondary Structure  | `--output` (dir)   | Auto generates all formats (.png and .ct) named by sequence ID |
| Secondary Structure  | `--output` (file)  | Auto detects format by extension (.npy, .png, .ct)  |
| Clustering           | `--output`         | t-SNE cluster image(s) (.png, etc.)                 |
| Classifier Training  | `--output`         | loss_history.png, accuracy_history.png              |
| Expression Training  | `--output`         | loss_history.png, accuracy_history.png              |

**Usage Examples**:
```bash
# Save secondary structure visualization
# Smart output: specify directory, generates all formats (uses sequence ID as filename)
ReRNAFM predict_ss --sequences_file seq.fasta --output ./results/
# Will generate: maqe.png and maqe.ct (if the sequence ID is "maqe")

# Save clustering result
ReRNAFM cluster --fasta_folder /path/to/fasta --output cluster.png

# Save training history
ReRNAFM classify --fasta_folder /path/to/fasta --output ./results/
```

## Summary

| Function                | Training Needed? | Description                       |
|-------------------------|-----------------|-----------------------------------|
| Sequence Embedding      | ❌ No           | Uses pretrained model             |
| Secondary Structure     | ❌ No           | Uses pretrained model             |
| t-SNE Visualization     | ❌ No           | Data analysis method              |
| RNA Family Classification | ✅ Yes         | Classifier must be trained        |
| mRNA Expression Prediction | ✅ Yes         | Classifier must be trained        |

**Key Points**:
- The RNA-FM base model is pretrained—no training is necessary
- For classification, you need to train a simple classifier using the embeddings
- Training the classifier usually takes just a few to several dozen minutes depending on your dataset size
- **All images can be saved to file** — suitable for use on headless servers
